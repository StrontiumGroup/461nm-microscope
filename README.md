# 461-nm Microscope Objective

CAD files for a high-resolution microscope objective designed for imaging ultracold strontium atoms at a wavelength of **461 nm**.

The objective achieves a spatial resolution of **0.63 µm** and is described in the following publication.

## Publication

**Microscope objective for imaging atomic strontium with 0.63 micrometer resolution**

I. H. A. Knottnerus, S. Pyatchenkov, O. Onishchenko, A. Urech, F. Schreck, and G. A. Siviloglou

*Optics Express* **28**(8), 11106–11116 (2020).

[https://doi.org/10.1364/OE.388809](https://doi.org/10.1364/OE.388809)

## CAD Files

This repository contains CAD files for the microscope objective described in the publication above.

## Enhanced Version: Rb and Sr

An enhanced version of the microscope objective, supporting imaging at both rubidium (Rb) and strontium (Sr) wavelengths, is described in the following master's thesis:
